Core Capabilities

🛡️

Zero Contact Uploads

Your privacy is absolute. All call evaluation and rule matching happen entirely on your device. Your address book is never uploaded or shared with any server.

⚙️

Advanced Regex Engine

Create powerful filters using Regular Expressions. Block entire area codes, specific prefixes, or complex number patterns with professional-grade precision.

⚡

QuickJS Plugins

Extend functionality with custom JavaScript plugins. Query public APIs or community databases for caller ID in real-time, safely executing in a sandboxed environment.

📵

Silent Rejection

Automatically hang up on spam calls before your phone even rings. Prevent robocalls from leaving voicemails by instantly rejecting blacklisted numbers.

📝

Transparent Code

The source code is open and available for auditing. We believe security and privacy tools must be transparent so you can trust the software running on your device.

📱

Dual SIM & SMS Support

Configure independent rules for different SIM cards. The APK version also includes a robust SMS filtering engine to keep your inbox free of phishing and spam.
