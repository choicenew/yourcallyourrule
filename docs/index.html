Frequently Asked Questions

Everything you need to know about YourCallYourRule (CallShield).

How does YourCallYourRule guarantee 100% offline privacy?

YourCallYourRule evaluates incoming phone numbers on-device using local regular expression matchers and offline database subscriptions. Your contacts list is never uploaded or shared with any central server.

What is the difference between Google Play and GitHub Releases?

Google Play policies restrict SMS permission access. The Google Play version focuses exclusively on Call Blocking. The GitHub Release version contains both Call Blocking and SMS Spam Filtering.

How do custom QuickJS plugins work?

You can import JS scripts that query public web endpoints for unknown numbers on demand, allowing community-driven phone lookup without sacrificing your phonebook.
