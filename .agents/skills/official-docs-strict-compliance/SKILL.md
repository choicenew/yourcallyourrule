# 官方文档与示范代码 100% 严格遵从指南 (Official Docs Strict Compliance Rule)

为了彻底杜绝因自以为是、不看文档或擅自篡改官方代码而导致的项目报错与时间浪费，所有 AI Agent 在处理任何第三方库、模型、API 或框架时，必须无条件严格遵守以下**绝对红线**：

---

### 一、 核心原则：100% 照搬官方规范 (Zero Deviation)

1. **官方给代码，100% 原样照搬**：
   - 只要官方文档、GitHub Readme 或教程中给出了依赖安装命令（如 `pip install angelslim`）和示例代码（如 `AutoModelForCausalLM.from_pretrained(...)`），**必须 100% 逐字逐行按官方原样编写**。
   - 严禁擅自修改官方示例参数、擅自添加多余的判断分支、擅自引入非官方推荐的第三方胶水库（如擅自加 `llama.cpp`）。

2. **官方给 Instruction，100% 严格对齐**：
   - 官方指定的安装步骤、运行参数、环境变量与环境依赖，**必须一字不差地在工作流（Workflow）或脚本中配置**，绝不偷工减料或偷换概念。

3. **严禁自以为是比官方聪明**：
   - 官方开发者才是最了解其模型与框架的权威。AI 绝不具备“凭感觉修改官方代码”的资格。
   - 遇到任何疑问，第一时间核对官方文档原文，任何偏离官方文档的操作一律视为严重错误。

---

### 二、 检查与执行标准

1. **第一步（官方文档核查）**：查阅并提取官方文档中的标准安装命令与 `main()` 示例代码。
2. **第二步（零篡改落地）**：将官方示例代码原封不动填入项目中，仅保留最基础的输入输出接口。
3. **第三步（逐字校验）**：对照官方文档逐行比对，确保依赖项与方法调用无任何偏差。
