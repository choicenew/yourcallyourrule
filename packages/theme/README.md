# Pyro Theme & Design System Suite (`packages/theme`)

Standalone, decoupled theme palette and design system package suite completely independent of `telephony` or business packages.

---

## 📁 Package Topology

```text
packages/theme/
├── pyro_theme_protocol/  # Theme Enums, Material 3 color palettes & typography contracts
├── pyro_theme_hub/       # Theme mode state manager (ThemeHub.instance)
└── pyro_theme_ui/        # Adaptive theme builder & Material 3 dynamic theme wrappers
```
