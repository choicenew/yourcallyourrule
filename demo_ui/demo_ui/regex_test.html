常用正则表达式示例

点击示例可自动填充到测试框

中国大陆手机号码
^1[3-9]\d{9}$
匹配以1开头，第二位是3-9，后面跟9位数字的手机号
400电话
^400\-?\d{3}\-?\d{4}$
匹配400开头的电话号码，中间可能有连字符
座机号码
^0\d{2,3}\-?\d{7,8}$
匹配以0开头，后面跟2-3位区号，可能有连字符，最后是7-8位号码
国际电话号码
^\+?\d{1,4}?[\-\.\s]?\(?\d{1,3}?\)?[\-\.\s]?\d{1,4}[\-\.\s]?\d{1,4}[\-\.\s]?\d{1,9}$
匹配各种格式的国际电话号码
95开头的服务号码
^95\d{3}$
匹配95开头的5位服务号码

正则表达式基础语法

常用语法参考

符号 说明 示例
^ 匹配字符串开头 ^1 匹配以1开头的字符串
$ 匹配字符串结尾 9$ 匹配以9结尾的字符串
\d 匹配一个数字 \d{3} 匹配3个数字
\w 匹配一个字母、数字或下划线 \w+ 匹配一个或多个字母、数字或下划线
[] 匹配方括号内的任意一个字符 [0-9] 匹配一个数字
* 匹配前面的表达式0次或多次 \d* 匹配0个或多个数字
+ 匹配前面的表达式1次或多次 \d+ 匹配1个或多个数字
? 匹配前面的表达式0次或1次 \d? 匹配0个或1个数字
{n} 匹配前面的表达式恰好n次 \d{3} 匹配恰好3个数字
