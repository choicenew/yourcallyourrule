# Your Call Your Rule - 现代化HTML UI设计

这个目录包含了使用Tailwind CSS重新设计的Your Call Your Rule应用的现代化Web界面。这些HTML文件提供了一个完整的UI设计参考，可以直接在浏览器中查看和交互。

## 文件结构

- `index.html` - 主页面，包含应用的主要功能和导航
- `onboarding.html` - 引导页面，用于新用户初始设置
- `dashboard.html` - 仪表盘页面，显示统计数据和任务管理
- `callerid.html` - 来电识别设置页面，用于自定义来电显示
- `blacklist.html` - 黑名单管理页面，用于管理拦截的联系人

## 特点

- **响应式设计**：所有页面都适配移动设备和桌面浏览器
- **现代UI**：使用Tailwind CSS实现的现代化界面
- **在线资源**：所有资源（字体、图标等）都使用CDN链接，可以直接在线访问
- **交互功能**：包含基本的JavaScript交互效果

## 如何使用

1. 直接在浏览器中打开HTML文件即可查看设计
2. 点击页面中的导航链接可以在不同页面之间切换
3. 尝试交互元素（如开关、滑块、按钮等）体验功能

## 设计亮点

- **主题色系**：使用绿色（#0ACA6D）作为主色调，搭配粉色（#FF809A）作为强调色
- **卡片式布局**：采用卡片式设计，增强视觉层次感
- **自定义组件**：包含轮播、开关、进度条等自定义组件
- **图标系统**：使用Font Awesome图标库提供丰富的图标选择

## 开发说明

这些HTML文件可以作为UI参考，用于：

1. 前端开发人员实现实际功能
2. UI/UX设计师进一步优化界面
3. 产品经理评估新功能和用户体验

所有页面都使用了Tailwind CSS的CDN版本，无需本地安装即可查看完整样式。
